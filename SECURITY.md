# Security Policy

## Supported Versions
| Version | Supported |
|---|---|
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability
Security vulnerabilities in payment and fraud detection systems are taken with highest priority.

Please **do not** open public GitHub issues for security vulnerabilities. Instead, report potential vulnerabilities directly to the maintainers or via GitHub Private Vulnerability Reporting.

We commit to acknowledging receipt within 48 hours and providing a remediation timeline within 7 business days.
